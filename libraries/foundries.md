# Foundries and libraries to research live (not verified)

This is a research map, not a font database. **Every fact taken from these sources starts as `UNVERIFIED`** until you confirm it on the foundry's own site and license page. Licensing models differ a lot. Read the EULA for each scope you need (see `references/licensing.md`).

## Libre / free (licenses vary, check each family)

| Source | Why look | Check |
|---|---|---|
| Collletttivo | Italian collective of libre display and text faces | License per family |
| Use & Modify (Raphaël Bastide) | A curated list of libre typefaces with a strong experimental bent | Each entry links to its own license |
| The League of Moveable Type | One of the earliest open-source type foundries | OFL in most cases |
| Open Foundry | A platform for open-source fonts | License per family |
| Uncut.wtf | Catalog of free contemporary typefaces | It is an index. Check the licenses at the source |
| Badass Libre Fonts by Womxn | Libre fonts by women and non-binary designers | License per family |
| Bye Bye Binary | Inclusive and post-binary type research | License per family |
| Tunera Type Foundry | Libre foundry | License per family |
| Free Faces (freefaces.gallery) | Curated free faces | "A variety of free licences", so check each one |

## How to promote a lead to a verified entry

1. Open the family's page on the foundry site and note the designer, styles, axes and supported languages.
2. Open the EULA and record the scopes (desktop, web, app, logo, broadcast), how web use is metered (pageviews or domains), and whether **subsetting** is allowed.
3. Record it with the schema in `libraries/README.md`, with status `VERIFIED (url, date)`.
